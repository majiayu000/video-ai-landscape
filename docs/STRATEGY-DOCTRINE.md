## 0. 纲领一句话

**「格式免费，验收收费」**：把契约 schema 捐成开放标准，把商业价值全部押在标准无法覆盖的三件事上——**验收执行、角色资产、跨厂商一致性**；以"帮厂商卖"的增量关系存活于碎片化窗口期；按 4-6 年周期规划，穿越一次死亡谷。

## 1. 七条第一性原理（游戏物理定律）

每条都有 ≥2 个历史案例背书（证据链见第四轮研究笔记）：

- **P1 碎片化定律**：抽象层价值 ∝ 下层碎片化程度；下层收敛出单一赢家之日就是中立层贬值之时。*碎片化是计时器，不是永恒结构。*（Stripe/Twilio 立于千级碎片下层而兴；Docker 在 OCI+K8s 收敛后被挤出平台层；OpenRouter 碎片化红利期仅约 3 年）
- **P2 状态定律**：无状态的转发/路由没有独立生存权——必被收购或利润归零；可积累的状态资产（工作流、授权、验收记录、资产库）才有。*（OpenRouter 无状态转发，$1.3B→82 天后被 Stripe 收编；Zapier 持工作流状态+应用目录，$1.3M 融资活 14 年）*
- **P3 增量定律**：对下层"帮它卖"（增量关系）则共存；在下层玩家之间做裁决式路由并截流，必招官方下场。*（Stripe 给卡组织带交易量；Plaid 被 Chase 定性"massively taxing"后被迫签受控付费协议）*
- **P4 商品化方向定律**：一层商品化时，利润流向它的互补品——**对最终结果负责的那一层**。生成调用价 3 年跌 1000x、Veo 5.5 个月跌 8x，利润沉向算力/应用/数据/验收。*（Christensen 保守吸引力利润定律；LLM 栈已实证）*
- **P5 标准定律**：标准化精确商品化它触碰的那一层——**捐出的 schema 永远不是护城河，护城河在执行与认证**。*（Docker 捐 OCI：格式永生、公司出局；SmartBear 捐 OpenAPI 靠工具存活；卡组织报文格式公开而清算网络垄断至今）*
- **P6 官方化定律**：平台官方做你这层 = 死刑判决书，纯路由/纯转发最先死；活下来的是**官方没有动机做、又需要跨厂商中立**的资产。*（Twitter 2012 埋雷 2023 执行；OpenAI Assistants API 吃掉一层包装；厂商官方 MCP/skills 正在视频领域重演）*
- **P7 时间定律**：独立中间件窗口逐代减半：云约 8 年 → 移动约 4-5 年 → LLM 约 12 个月；**视频波估计 6-12 个月**（供应商提前占位+建设者带 LLM 波经验入场）。且抽象层中途必有一次估值腰斩/信任危机式死亡谷。*（云/移动/LLM 三波复盘；Stripe $95B→$50B、Twilio 两轮裁员、Plaid 腰斩）*

## 2. 位置判断（我们在线条上的哪里）

**当前相位 ≈ LLM 波的 2023 年 2-4 月**（聚合层密集 Show HN、16 家比价表出现、GitHub 年内新增 2678 个视频生成仓库）——但厂商官方 MCP 已提前占位，收编与爆发同季出现，相位较 LLM 波压缩 2-3 倍。

**相位仪表盘（四盏灯）**：
1. ☑ 同质聚合层密集上线（已亮：VideoRouter/Velokey/useapi/APIMart）
2. ☑ 跨厂商比价表出现（已亮：useapi 16 家 Seedance 定价表）
3. ☑ 应用层自建仓库数超过工具包装层（已亮：2678 个仓库、≥8 个轮询轮子）
4. ☐ **官方开始内置验收/角色功能**（未亮——**此灯一亮，立即从扩张转向深耕存量与收租**）

**强度判定：全力冲刺，但方向限定**（只做厂商无收编动机的中立资产，不在价格路由上消耗任何资源）。

## 3. 打法准则（决策启发式——遇到 X 永远选 Y）

| # | 遇到这类选择 | 永远选 | 依据 |
|---|---|---|---|
| H1 | 统一 API 转发 vs 有状态资产 | **状态资产**（验收数据集、角色资产库、版本化契约） | P2：OpenRouter vs Zapier 的两个结局 |
| H2 | 厂商投资/排他合作邀约 | **拒绝**；可做厂商付费的"契约兼容性认证" | P3 + Visa-Plaid 正反面；绑定消灭中立价值与多方竞价 |
| H3 | "帮用户少付厂商钱"的功能 | **不做**（自杀线）；做 per-vendor 增量回流报告 | P3：平台容忍条件一=不碰核心变现 |
| H4 | schema 什么时候捐 | **触发器**：≥2 家中立路由商+≥1 家厂商采纳，或中立性被公开质疑 → 立即捐（schema+商标打包），保留执行器商业权 | MCP 已跑成剧本（12.5 个月捐 AAIF）；Markdown/RSS 拒捐致分叉 |
| H5 | 重的部分（托管/算力/带宽） | **外包或 BYO 收费**，成本曲线必须轻 | ElectricSQL/托管失控关闭独立选项；37signals 模式 |
| H6 | 开源模型 vs 云端模型 | **自托管一等公民**（Wan/H3 本地与 Veo 云端同构验收） | 开放权重拉平价格地板的时滞仅 1 周-3 个月 |
| H7 | 计费模式 | 向"按验收通过的结果计量"演进；**绝不按秒转售** | P4：按结果收费者拿利润，按成本转售者无定价权 |
| H8 | 用户身份与关系 | **归开发者**；不做任何厂商的"客户端" | P3 容忍条件二；CLI 拥有工作流是高危特征，须以"合同与验收记录归用户"对冲 |
| H9 | 里程碑节奏 | **按季度交付外部可见资产**；连续两季度无外部可见资产 = 落后 | P7：按 18 个月排期等于自杀 |

## 4. 三情景推演（2027 / 2030）

| 情景 | 概率（定性） | 世界状态 | 我们的应对 |
|---|---|---|---|
| **基准：寡头+长尾并存** | 最高 | 2-3 家头部模型 + 开源长尾；厂商官方 MCP 齐备但互不兼容；验收/角色资产无官方方案 | 契约层成为事实标准（触发 H4 捐出）；验收认证与角色资产双收入；**这是计划设计所依据的情景** |
| **乐观：碎片化加深** | 中 | 开源权重+价格战使模型层彻底商品化，新模型月月更替 | 抽象价值最大化（P1）；重心移向迁移契约与一致性评测——"换模型不换资产"成刚需 |
| **悲观：单家赢家通吃** | 低-中 | 某视频模型碾压式收敛市场 | 预设 pivot：转做该赢家生态的**验收/合规/认证层**（厂商无法自我评级，P4 利益冲突仍在）；角色资产格式随其生态延续 |

## 5. 终局选项（四条路 + 从现在开始攒的筹码）

| 路线 | 现实概率 | 条件与锚点 |
|---|---|---|
| **独立盈利存续（主路线）** | 高 | 37signals/Zapier 路线：契约与验收是纯软件（便宜、可永久独立）；角色资产托管 BYO 化保持轻成本 |
| **被收购（期权，非目标）** | 中 | 若成互操作枢纽，买家排序：云平台 > 模型厂商 > Agent 平台；对价锚定买方战略价值（NVIDIA $12.9B 收 HF、Cloudflare-Replicate 先例）——**保持多买方竞价格局，拒绝独家绑定** |
| IPO | ≈0（差 2-3 个数量级：门槛 $150-200M 收入+50% 增速） | 不作为设计目标，但按同一套可审计标准记账 |
| 捐标准（非终局，是过程） | 已排期 | 见 H4 触发器 |

**从现在就攒的三样筹码**：① 公开的中立承诺（拒绝单厂商绑定的书面政策）；② **可完整导出 + OSS 兜底实现**（一鱼三吃：获客卖点/收购抬价筹码/最坏情况用户保护——Replicate"API 不变"与 ElectricSQL 关停的正反例）；③ 干净账本（收入可预期、合同干净、无异常关联授权——所有退出路径共用同一套尽调材料）。

## 6. 反纲领（什么会杀死我们——每季复核清单）

1. **被收编成某厂商的渠道**（接受独家投资/合作那一刻发生）
2. **做成客户端/拥有用户关系**（触发平台容忍条件二红线）
3. **依赖任何单一厂商的免费配额或慷慨限免**（补贴随时撤回；架构上限：任一 vendor 停供 24h 内，验收/回放/角色资产仍可离线运行）
4. **把价值押在可被标准化的格式上**（schema 从第一天按"会被捐出/被抄走"设计）
5. **在路由/比价/转售上消耗资源**（正在崩塌的层，且必招官方下场）
6. **按 LLM 波速度排期**（视频波窗口减半再减半）
7. **成本结构变重**（托管/算力失控自动关闭独立选项）
8. **错过第四盏灯**（官方内置验收/角色功能后仍扩张 = 与平台对撞）

## 7. 与执行计划的联动

- 纲领的 H1/H7 直接决定执行计划三支柱顺序（契约→判片→角色资产）与"不做转售"红线。
- M0-M3 的每个里程碑交付物都对应一条"外部可见资产"要求（H9）。
- 相位仪表盘第四盏灯（§2）接入执行计划 M4 的决策点：亮灯即转向。
- 死亡谷预案（P7）：2027-2028 预设"厂商集体官方下场+融资寒冬"——验收层必须在危机前成为收入主干（厂商无法自我评级的刚需）。

---

**纲领一句话的展开**：我们不在"生成"上与任何人竞争——生成正在变便宜，这是我们的顺风；我们在"什么算做好了"与"角色是谁"这两件不会变便宜的事情上，做所有厂商与所有聚合站都因立场坐不上去的那一层。
