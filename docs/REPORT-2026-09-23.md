# 第一部分 · 执行摘要

## 1.1 五个核心判断（全部有一手证据链）

1. **接入层形态已定型**：SKILL.md + MCP + CLI 三件套。PixVerse（中国唯一全做齐）、Tavus、Runway（官方托管视频 MCP 第一家）已亲自验证——这是既成事实，不再是判断。
2. **厂商集体收缩回围墙**：fal 全押自家 Agent、Higgsfield 转向 ChatGPT 宿主、HeyGen 收拢渲染并日落 v1/v2 API、Pika 砍旧 API。每家只覆盖自己，**跨厂商公共层无人做**。
3. **纯路由/聚合正在失去护城河**：Runway Model Router、VideoRouter、Hedra 三方挤压；OpenRouter（无状态路由的标杆）2026-08-19 官宣被 Stripe 收编——融资后 82 天，终局实证。
4. **价值沿栈上移，L5 三个空位结构性无人能做**：跨厂商任务契约、生成后判片闭环、角色一致性资产——厂商做有利益冲突（无法自评），聚合站做无立场（只会路由）。需求侧已验证：90 天内 GitHub 出现 ≥8 个自建轮询/续跑仓库。
5. **窗口以月计**：视频开发者波相位 ≈ LLM 波 2023 年 2-4 月；独立中间件窗口逐代减半（云 8 年→移动 4-5 年→LLM 约 12 个月），**视频波估计 6-12 个月**。

## 1.2 纲领一句话

**「格式免费，验收收费」**——契约 schema 捐成开放标准；商业价值押在标准无法覆盖的三件事：验收执行、角色资产、跨厂商一致性；以"帮厂商卖"的增量关系存活；按 4-6 年周期规划穿越一次死亡谷。

# 第三部分 · 战略纲领（为什么这么打）

## 3.1 七条第一性原理（每条 ≥2 个历史案例背书）

| # | 定律 | 杀手证据 |
|---|---|---|
| P1 | 碎片化定律：抽象层价值 ∝ 下层碎片化；碎片化是计时器不是结构 | Docker 在 OCI+K8s 收敛后失去平台；OpenRouter 红利期仅约 3 年 |
| P2 | 状态定律：无状态转发必被吞或归零；状态资产才有生存权 | OpenRouter $1.3B→82 天被 Stripe 收编 vs Zapier $1.3M 融资独立 14 年 |
| P3 | 增量定律：帮下层卖则共存；裁决截流必招杀 | Plaid 被 Chase 定性 "massively taxing" 后被迫签受控付费协议 |
| P4 | 商品化方向定律：利润流向"对结果负责"的互补品层 | LLM 推理价 3 年跌 ~1000x；Veo 5.5 个月跌 8x；利润沉向算力/应用/数据 |
| P5 | 标准定律：捐出的 schema 永远不是护城河，护城河在执行与认证 | Docker 捐 OCI 格式永生公司出局；SmartBear 捐 OpenAPI 靠工具存活 |
| P6 | 官方化定律：平台官方做你这层=死刑判决，纯路由先死 | Twitter 2012 埋雷 2023 执行；厂商官方 MCP/skills 正在视频领域重演 |
| P7 | 时间定律：窗口逐代减半（8y→4-5y→12m→视频波 6-12m）；必有一次死亡谷 | 三波复盘；Stripe $95B→$50B、Twilio 两轮裁员、Plaid 腰斩 |

## 3.2 位置与仪表盘

**当前相位 ≈ LLM 波 2023 年 2-4 月**；强度判定=**全力冲刺但方向限定**。
四盏灯：①聚合层密集上线 ☑ ②比价表出现 ☑ ③应用层自建仓库爆炸 ☑ ④**官方内置验收/角色功能 ☐——亮即从扩张转向收租**（接入执行计划 M4 决策点）。

## 3.3 九条决策启发式（遇到 X 永远选 Y）

1. 统一转发 vs 状态资产 → **状态资产**
2. 厂商投资/排他合作 → **拒绝**（可做厂商付费的兼容性认证）
3. "帮用户少付厂商钱"的功能 → **不做（自杀线）**
4. schema 何时捐 → **触发器即捐**（≥2 中立路由商+1 厂商采纳，或中立性被质疑；schema+商标打包，保留执行器商业权——MCP 发布 12.5 个月捐入中立基金会，剧本现成）
5. 重的部分（托管/算力）→ **外包或 BYO 收费**
6. 开源 vs 云端 → **自托管一等公民**（开放权重拉平价格地板时滞仅 1 周-3 月）
7. 计费 → 向"按验收通过的结果计量"演进，**绝不按秒转售**
8. 用户身份与关系 → **归开发者**，不做任何厂商客户端
9. 节奏 → **按季度交付外部可见资产**；连续两季度无 = 落后

## 3.4 终局与反纲领

**终局**：独立盈利存续=主路线（契约与验收是纯软件，成本必须永远轻）；被收购=期权非目标（买家排序：云平台>模型厂>Agent 平台；保持多买方竞价）；IPO≈0 不作设计目标。**三筹码现在就攒**：书面中立承诺、可完整导出+OSS 兜底、干净账本。

**反纲领（什么会杀死我们，每季复核）**：被收编成渠道 / 做成客户端 / 依赖免费配额 / 价值押在格式上 / 在路由上耗资源 / 按旧波浪速度排期 / 成本变重 / 错过第四盏灯。
