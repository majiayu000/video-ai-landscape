# 视频厂商对比，以及阿特拉斯该怎么做

写于 2026-09-22。

这份文档记两件事。前面是视频厂商的商业对比。后面是阿特拉斯在技能、命令行、MCP 和接口上该怎么做。

范围就这一条线。不做编程套餐，不做多人团队账户，不做客户管理软件。

材料从哪来：这个仓库 2026-09-21 的厂商调研，Higgsfield 技能仓库 `v0.12.0` 的正文，以及 2026 年 9 月核对过的公开页面。公司和媒体报的收入、估值不当成已经入账的数字。同一条模型在不同页面上的价格不一致时，表里写明，不合成一个数。

## 1. 他们实际在卖什么

这个仓库原来的表比的是有没有接口、命令行、技能。下面比的是客户换一家就丢什么。

| 厂商 | 自己的视频模型 | 别人的模型 | 人打开就能用的产品 | 程序调用的门 | 客户换一家就丢的东西 |
|---|---|---|---|---|---|
| Higgsfield | 有。Soul、Cinema Studio，用来锁脸和电影感 | 有。技能默认正经视频用 Seedance 2.5，便宜镜头用 Kling 3.0 | 网页工作室、广告工作室、无限套餐 | 命令行、托管 MCP、9 个技能、单独的美元 API | 训练出来的脸的编号、从网址导入的商品、钩子、场景、品牌套件、成片分数 |
| Runway | 有。Gen-4.5、改片子的 Aleph | 有。转售 Veo、Seedance、Wan、海螺 | 剪辑和生成的网页 | 两套 MCP、11 个技能、Python 和 Node 软件包。没有自己的命令行 | 时间线上的改片。没有商品库和脸的编号 |
| 可灵，快手 | 有。运动质量是本业 | 不靠转售别人 | 可灵 App | 官方接口用短时令牌。没有官方命令行。最常用的 MCP 是社区做的，还经常走转售商 | 模型本身。2026-04-21 的消费者条款禁止把这项服务嵌进别人的产品或转卖 |
| 字节 Seedance | 有。Seedance、Seedream | 不靠转售 | 即梦、豆包、Dreamina、CapCut | 火山方舟、BytePlus。没有官方视频命令行，官方也没有视频 MCP | 创作软件里的排队、会员、剪辑时间线上的按钮。开发者接口是另一扇门 |
| Pika | 有，但不再自己做开发者门 | 不转售别人 | 给普通人用的产品 | 2025-12 起官方接口交给 fal。没有自己的命令行、MCP、技能 | 几乎没有。开发者关系让给了 fal |
| Luma | 有。Dream Machine | 这份调研没把它写成转售商 | Dream Machine | 官方接口、Go 命令行、官方 MCP、Python 和 JS 软件包。没有官方技能 | 调研没写他们有商品库或脸的编号 |
| MiniMax 海螺 | 有。视频只是模型家族的一支 | 不靠转售视频 | 海螺产品 | 官方接口、官方 MCP、官方软件包。没有命令行，没有视频技能 | 模型。Higgsfield 只在要便宜、要物理效果、不要声音时才叫它 |
| Google Veo | 有 | 不转售 | Gemini 应用、Vertex | 两条官方接口。没有专用命令行，没有视频技能 | 模型、云账号、企业合同 |
| OpenAI Sora | 有 | 不转售 | ChatGPT 里的视频 | 官方视频接口，有命令行。官方技能目录里没有视频技能 | 模型。视频没有被做成一套广告存货 |
| fal | 不靠一个自有视频品牌 | 有。一千多个端点，也接把接口交出来的厂商 | 网页 Agent，还在早期。对话本身不加价 | 模型接口、命令行、17 个社区技能、每个模型一份机器可读说明 | 跑模型的机器和队列。多步工作可以收成一次调用。客户的商品和脸不在这里 |
| 阿特拉斯 | 没有基础视频模型。名下有放大、清理和一批工作室端点 | 有。2026-09-22 拉到的目录里，控制台可见视频端点 231 个 | 网页模板：产品图、试穿、食物、广告 | 命令行、MCP、3 个技能。明确不做自己的软件包 | 目前主要是钥匙和余额。技能还没有脸的编号、商品库、成片分数 |

## 2. 钱从哪扇门进来

| 厂商 | 人用的时候怎么付钱 | 程序调用怎么付钱 | 两套账 | 技能和命令行走哪一套 |
|---|---|---|---|---|
| Higgsfield | 月费加积分。无限生成只在网页上，忙的时候会降速 | 另一笔预存美元，按秒或按张。2026-09-16 的文章写：网页积分和无限都不能用在 API 上 | 故意分开，避免无限套餐被程序刷光 | 本仓库记的是命令行和 MCP 吃网页积分。和 9 月那篇文章已经不一致，以账号里实际扣的那一笔为准 |
| Runway | 积分，大约 1 美分一分 | 同一套积分。Gen-4.5 约每秒 0.12 美元，Aleph 改视频约每秒 0.28 美元 | 不拆成两笔 | 技能里的脚本直接打接口，钥匙只能放环境变量 |
| 可灵 | App 里的会员和积分 | 官方接口按秒，高档大约每秒 0.11 美元 | 产品和接口分开 | 没有官方技能。社区 MCP 常常把提示词送到转售商 |
| 字节 | 即梦是人民币会员。Dreamina 是美元月费 | BytePlus 按量，和即梦积分不是同一个钱包。先要有余额或资源包。核对到的门槛包括超过 30 美元余额 | 分开 | 没有官方视频技能。别人的技能把 Seedance 写成默认 |
| Pika | 自己的产品里付钱 | 开发者按 fal 的价付 | 人的产品和开发者接口不在一家 | 没有 |
| Luma | 产品内额度 | 这个仓库记大约每秒 0.10 到 0.30 美元 | 调研没写成双轨 | 有命令行和 MCP，没有技能 |
| 海螺 | 套餐，没有一张简单的官方单价表 | 按条，这个仓库记大约一条 0.08 到 0.28 美元 | 套餐和接口不是同一张价目 | 有 MCP，没有技能 |
| Veo | 订阅或云账单 | 按秒，大约 0.05 到 0.60 美元 | 应用和云是两家产品 | 没有视频技能 |
| Sora | ChatGPT 订阅 | 按秒，大约 0.10 到 0.50 美元 | 订阅和接口分开 | 没有视频技能 |
| fal | Agent 用额度，只为真正跑的模型付钱 | 按次或按 GPU 秒 | 调用、自己部署、包小时机器是三笔账 | 技能只是命令行的说明书，先查价再提交 |
| 阿特拉斯 | 模板按张或按时长，失败不扣 | 预存美元。图像多在提交时扣，按 token 的视频在完成时扣。提交前有不扣费的估价接口 | 媒体是一笔现金 | 技能教人自己发请求。价格写在正文里，会和当天目录不一致 |

同一条 Kling 3.0，这个仓库记 Higgsfield 渠道大约每秒 0.042 美元，Higgsfield 自己 2026-09-16 的 API 价目是每秒 0.112 美元。不把这两个数当成同一个价。

## 3. 技能在替他们做什么决定

| 厂商 | 技能大概几份 | 助手被要求先做什么 | 默认视频 | 有没有可以反复用的存货 |
|---|---|---|---|---|
| Higgsfield | 9 | 先定任务：广告、封面、品牌、讲解、游戏。不要先比价 | Seedance 2.5。广告走 Marketing Studio，不暴露底下是谁 | 有。脸、商品、钩子、场景、品牌、成片分数 |
| Runway | 11 | 跑他们写好的脚本。钥匙不许出现在命令里 | 本仓库写他们的默认也是 Seedance 2.5 | 没有商品和脸。有改视频的 Aleph |
| fal | 17 | 用命令行，先读模型说明，不要自己编模型编号 | 按任务选 | 没有。有一次调用跑完多步的工作流 |
| 阿特拉斯 | 3，外加 25 篇做法说明 | 先查目录和参数，再发请求。正文仍抄了价格 | 种子技能把 Seedance 2.5 写得很深，其余靠目录 | 工作室端点有名字，技能里还没有商品编号和脸的编号 |
| Luma | 0 | 没有官方技能 | 无 | 调研没写 |
| 可灵、字节、海螺、Veo、Sora、Pika | 0，或只有社区 | 没有厂商自己的助手剧本 | 无 | 模型或 App 里的会员，不是技能里的存货 |

阿特拉斯名下已经有的工作室端点，当天目录里能看到这些名字：`atlascloud/studio/product-visuals`、`food-motion`、`virtual-try-on`、`ugc-ad`、`tvc-maker`、`trend-remix`。文档索引把它们和普通模型放在一起。抽查过的 Food Motion 没有节点图，走的是一次视频生成。其余几份请求字段还没有逐份打开。

## 4. 他们为什么这样，以及阿特拉斯学哪一层

| 厂商 | 为什么不把模型卖完就停 | 下一步在占什么 | 阿特拉斯学不了 | 阿特拉斯能学 |
|---|---|---|---|---|
| Higgsfield | 模型每月会换谁最好。留住客户的是脸、商品和广告流程 | 广告团队的月费，再加到网站和成片打分 | 已经有的消费品牌和无限套餐 | 把商品、人、一次成品做成命令行和 MCP 里的对象 |
| Runway | 专业用户要的是改片子 | 继续当剪辑工具，并把接口做得让企业敢接 | Aleph 这种改视频的自家模型 | 钥匙和生成结果的规矩写进技能 |
| 可灵 | 运动质量就是产品。条款不准别人嵌他们的 App | 下一个模型版本，以及自己的 App | 模型本身 | 只接允许转售的开发者接口 |
| 字节 | 人搜的是即梦和 Dreamina | 模型继续进剪辑软件。接口留给量大的公司 | 创作软件和分发 | 开发者门和即梦积分分开写 |
| Pika | 做不成开发者平台，就交给 fal | 留在给人用的产品里 | 无 | 某扇门做不厚，就不要四扇门都挂空招牌 |
| fal | 机器是他们的 | 多步生成变成一次调用，并让客户把模型部署上来 | 自己的 GPU | 一次调用完成多步。提交前先看价 |
| 阿特拉斯 | 现在卖的是一把钥匙打到很多模型 | 若停在钥匙，比的是转售价。Higgsfield 已经在收上面那一层 | 无 | 工作室端点加上可重复使用的商品和人。三扇门用同一次请求 |

有模型的厂商在守模型和自己的 App。Higgsfield 在守广告团队的存货。fal 在守跑模型的机器。阿特拉斯现在守的是钥匙。

## 5. 方案

要做成的是模型这条线。阿特拉斯目录里的模型，命令行、MCP、技能都能调。三次调用用同一个模型编号，参数和价格都从当天目录读，不写死在说明书里。调用结束要拿到文件、任务号和实际扣费。商品图、试穿这类工作室端点只是目录里的几条，用来验证这条路，不是用来替换那几百个模型。

不做这些：自己的软件包、GPU 云、无限套餐、即梦那种创作软件、可灵 App 的嵌套、编程套餐、团队账户、把工作室重做成一张可导出的流程图。流程图在更新日志里有画布，没有核对到对外的图接口。在接口出现之前，不在技能里重做一套。

### 第一周：用一个模型证明三扇门是同一次调用

从目录里选一个你真的会反复用的模型。出图或出视频都可以。不要一次选十个。工作室端点可以选，普通的 Seedance、Wan、Kling 也可以选。选它是为了试路，不是因为它比别的模型重要。

第 1 天，打开这个模型当天的参数说明，把必填字段抄下来。

第 2 天，用接口做完一次。能估价就先估价。估价接口是 `POST /api/v1/model/calculate`，不扣费。然后提交。记下估价金额、任务号、文件地址。失败了先看有没有扣钱，不要马上再发一次。

第 3 天，用 `atlas` 命令发同一份内容。模型编号和结果要和昨天一致。命令行做不到的能力写明「做不到」，不要换一个模型假装做成了。

第 4 天，用 MCP 再发一次。三次的模型编号必须相同。

第 5 天，改技能里关于这个模型的句子。删掉写死的价格。改成：先读当天的参数说明，提交前先估价，用这个编号。

第 6 天，把三次里不一样的字段改成一样。改不了的写成已知差别。

第 7 天，留下记录：模型编号、三份请求、三份结果、花了多少钱、哪一扇门还做不到。

这一周的图片或视频只说明路走通了。目标仍然是后面能把同一套步骤用到目录里的其他模型上。

### 第一个月：把这套步骤铺到一批模型上

第 2 周，按任务各加一个模型，不按厂商凑数。至少覆盖：一张图、一段文生视频、一段图生视频。三个都走第一周的步骤。参数仍从当天目录读。

第 3 周，做参考图还能不能再用。接口如果给了可以再次引用的编号，第二次就用这个编号。如果只是临时地址，就写明「用过即丢」。不要发明一个所有模型都支持的资料地址。公开的资产库说明目前只覆盖 Seedance 2.0 和 2.0-Fast。

第 4 周，技能按任务写。出图、文生视频、图生视频各写清：先查目录，再估价，再提交。正文里不再维护一张价格表。用户点名要哪一家，就用那一家的编号。没点名时，写出选了哪个编号、为什么。25 篇做法说明里，先改和这三类任务有关的，其余先不动。

这个月结束时，三类任务都能从命令行和 MCP 拿到文件。换一个目录里已有的模型，只换编号，不改步骤。

### 第三个月：模型继续按任务加，不另起一套产品

每一类任务维持一个默认模型，默认从当天目录里选，并在结果里写明编号和扣费。用户点名的模型优先。工作室端点如果参数说明齐全，就作为「商品图」「试穿」这类任务的一个选项，和其他视频模型并列，不单独变成产品。

参考图或商品图如果已经有可重复使用的编号，就接着用。没有，就继续用临时地址，不假装有脸库或商品库。

n8n 只接文档里已经写了的用法：长视频做完后通知，不要一直查。ComfyUI 先不动，除非同一次请求已经能原样放进一个节点。

### 怎么算做完

| 时间 | 算做完 |
|---|---|
| 第 7 天 | 一个模型。接口、命令行、MCP 的模型编号相同，至少两扇门拿到文件。技能里没有这个模型的写死价格 |
| 第 30 天 | 出图、文生视频、图生视频三类都能拿到文件。再换一个目录里的模型，步骤不变 |
| 第 90 天 | 每类任务有一个写明的默认选择。结果里有模型编号和扣费。技能正文没有价格表。没有新的软件包，没有 GPU 页，没有无限套餐 |

第 30 天如果接口只给临时地址，结论写成「用过即丢」。这仍然算做完，下个月不去做一个假的资料库。
